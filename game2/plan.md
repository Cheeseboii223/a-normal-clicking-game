# Server builder plan

- Finished the full-screen server builder layout and focused it on a motherboard-style component tree.
- Kept the central board as the anchor, with CPU, RAM, GPU, PSU, and Case positioned around it.
- Each slot opens its own catalog and keeps the selected components highlighted.
- The builder validates socket, memory generation, case fit, GPU length, and PSU wattage before allowing a boot.
- The game now uses a fixed portrait resolution and a darker, more premium mobile UI finish.
- Sound effects are now active via lightweight Windows beeps for taps, purchases, server events, and resets.
- Final mobile polish pass complete: modal and overlay backgrounds are now bound to each widget so they stay aligned and do not get pinned to the corner.
- The hacked event pace and broader progression loop have been tuned for a smoother, more playable flow.
- The hacked battle now scales with upgrade power, so click upgrades, server bonuses, and tech-level progression all matter during the defense phase.
- Rebirth progression was added as a 30-rank ladder from Bronze I through Obsidian V, replacing the former extras menu with a dedicated rank-reset loop.
